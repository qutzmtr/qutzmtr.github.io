# 圣诞页背景音乐

默认情况下，圣诞页 (`../index.html`) 的背景音乐由浏览器实时合成，不加载任何音频文件，
所以首屏没有任何音乐下载开销。

如果你想换成自己的音乐，把文件放到这个目录，命名为 **`bgm.mp3`**：

```
specialpages/christmas26/audio/bgm.mp3
```

页面打开后会先检查这个文件是否存在：

- 存在：右下角按钮播放这份 mp3（循环播放）；
- 不存在：自动使用内置的合成音乐。

建议：

- 文件控制在 2 MB 以内，64–128 kbps 的 mp3 就够用；
- 请确认音乐的使用授权（团队自制、已获授权或公有领域作品）；
- 换文件后记得刷新缓存，或在文件名后加版本号（同时修改 `christmas.js` 里的路径）。
